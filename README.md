# silver-palace-assets

Тайлы подложки и иконки предметов для интерактивной карты [Silver Palace](https://broskiplay.ru/silver-palace-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/silver-palace/<u>/<x>/<y>.webp` — тайлы 256×256, WebP q95; u = 3 — родной масштаб (6144×4096 px), u = 0 — самый мелкий; `manifest.json` — список существующих тайлов
- `icons/*.webp` — иконки предметов из добычи
